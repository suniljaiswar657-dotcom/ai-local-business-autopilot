# AI Local Business Autopilot

An independent SaaS starter for local businesses to manage customer enquiries, leads, social content, follow-ups, and business analytics.

## MVP modules
1. AI customer support workspace
2. Lead management
3. Social media content generator
4. Customer follow-up tracker
5. Business analytics dashboard

## Stack
- Next.js App Router
- TypeScript
- CSS
- Vercel deployment target

## Budget
Designed for a ₹0-start approach. External AI, WhatsApp, database, and email integrations are not configured yet; each may introduce usage limits or costs.

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Project boundary
This repository is independent. Do not copy code, data, credentials, assets, or workflows from other projects into it without explicit approval.

## Current status
Foundation starter only. No live integrations, authentication, persistence, AI API, or deployment have been configured.
